            How to Use — Step by Step Guide
          

        

        


          
          

            

              
1

              
Connect Your Primavera P6 Database

            

            

              Go to Database & Settings and paste the full path to your PPMDBSQLite.db file.
              Click Connect — the app reads your project list directly from the SQLite database.
            

            
          


          


          
          

            

              
2

              
Upload the Delay Events Excel File

            

            

              Go to Upload Files. Download the template if needed, fill in your delay events, then drag and drop
              the file or click to browse. The file is saved server-side — its path is auto-filled into all analysis forms.
            

            
          


          


          
          

            

              
3

              
Run an EOT Analysis

            

            

              Go to Individual EOT or Combined EOT, select your baseline project, choose
              the milestone mode, and click Run. You will be redirected to the Live Logs
              viewer where you can watch the process in real-time via WebSocket streaming.
            

            
          


          


          
          

            
Feature Reference

            

              

                📊
                
Individual EOT
Simulates each delay event independently; produces per-delay EOT calculations.

              

              

                📈
                
Combined EOT
Applies all delay events in one combined schedule run for a global EOT figure.

              

              

                📦
                
Export XER
Packages delay projects as .xer files for import into P6 Professional / EPPM.

              

              

                🗑️
                
Delete Projects
Permanently removes delay projects from the SQLite database. Always export first!
